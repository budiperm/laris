# Kebijakan Privasi — LarisKasbon: Catat Utang

_Berlaku sejak: 23 Oktober 2026_

LarisKasbon ("aplikasi") adalah aplikasi Android untuk mencatat kasbon (utang) pelanggan warung dan pembayarannya.
Kebijakan ini menjelaskan data apa yang diolah aplikasi dan ke mana data itu pergi.

**Ringkasnya: semua data Anda disimpan di HP Anda sendiri. Pengembang tidak punya server dan tidak
menerima, melihat, atau menyimpan data Anda.**

## 1. Data yang Anda catat

- nama, nomor HP/WhatsApp, dan catatan pelanggan;
- kasbon (nominal, tanggal, keterangan, jatuh tempo) dan pembayaran;
- pengaturan aplikasi (misalnya nama toko dan PIN, disimpan sebagai hash).

Data ini disimpan di **penyimpanan internal HP Anda**. Aplikasi berjalan penuh tanpa internet dan tidak
meminta izin internet.

## 2. Kontak

Tombol **Ambil dari kontak** membuka aplikasi Kontak bawaan HP. Aplikasi hanya menerima **satu nama dan nomor
yang Anda pilih**; aplikasi tidak punya izin membaca daftar kontak Anda.

## 3. Berbagi lewat WhatsApp dan aplikasi lain

Pesan tagihan, kwitansi, dan file ekspor hanya dikirim ketika **Anda sendiri** menekan tombolnya. Aplikasi membuka
WhatsApp (atau aplikasi pilihan Anda) dengan teks yang sudah disiapkan; Anda yang memutuskan mengirimnya.
Pengembang tidak menerima salinannya.

## 4. Backup dan ekspor ke file

**Simpan backup** dan **Ekspor CSV** membuat file yang Anda simpan sendiri di tempat pilihan Anda (misalnya folder HP
atau Google Drive Anda) lewat pemilih file Android. File backup berisi seluruh data aplikasi; simpan di tempat
yang aman.

## 5. Yang tidak dilakukan aplikasi

- Tidak ada akun/registrasi, iklan, analitik, atau pelacak pihak ketiga.
- Tidak mengirim data ke server mana pun.
- Tidak mengakses lokasi, kamera, log panggilan, galeri, atau daftar kontak.
- Tidak menjual atau membagikan data kepada siapa pun.
- Aplikasi **tidak menyediakan atau menyalurkan pinjaman uang**, tidak menghitung bunga, dan tidak memproses
  pembayaran. Aplikasi ini hanya alat pencatatan antara Anda dan pelanggan Anda.

## 6. Data pelanggan Anda

Anda bertanggung jawab atas data pelanggan yang Anda catat. Catat hanya yang diperlukan dan hapus data yang tidak
dipakai lagi.

## 7. Menghapus data

- Hapus pelanggan, kasbon, atau pembayaran langsung di aplikasi.
- Hapus semua data: **Pengaturan Android → Aplikasi → LarisKasbon → Penyimpanan → Hapus data**, atau uninstall.
- File backup/ekspor yang Anda simpan sendiri dihapus dari tempat Anda menyimpannya.

## 8. Anak-anak

Aplikasi ditujukan untuk pelaku usaha dewasa dan tidak ditujukan untuk anak-anak.

## 9. Perubahan kebijakan

Jika kebijakan ini berubah, versi terbaru dipasang di halaman ini dengan tanggal berlaku yang baru.
